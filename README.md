# Learn-to-Earn Platform
A decentralized platform that rewards users with tokens for completing educational modules! 

## 🌟 Features

- Create educational modules with token rewards
- Track user progress and completion status
- Automatic token rewards upon module completion
- Token transfer capabilities
- Module activation/deactivation system

## 🔧 Contract Functions

### Administrative Functions
- `create-module`: Create new educational modules
- `deactivate-module`: Disable existing modules

### User Functions
- `complete-module`: Mark a module as completed and receive rewards
- `transfer`: Transfer tokens between accounts
- `get-balance`: Check token balance
- `get-module`: View module details
- `get-user-progress`: Check completion status

## 🚀 Getting Started

1. Deploy the contract using Clarinet
2. Create educational modules using `create-module`
3. Users can complete modules using `complete-module`
4. Earned tokens can be transferred using `transfer`

## 💎 Token Details

- Name: LEARN
- Symbol: LRN
- Rewards: Customizable per module

## 🔐 Security

- Owner-only administrative functions
- Progress tracking to prevent double rewards
- Safe token operations
